# API расписания

В локальной ветке `no-server` браузер обращается к источнику напрямую; `/api/health` и `/api/state` ниже относятся к PHP-версии на `main`.

Источник: https://mcd.nata-info.ru. Контракт неофициальный и может измениться. PHP-сборщик получает расписание запросом GET /api/v2?station=4127&build=1791447913. ID станции берётся из config/stations.json, ожидаемый build — из config/app.json. Сборщик запрашивает обе стороны без фильтра направления; предполагаемый лимит trains=10 не использовать.

## Поля источника

- Ответ станции: stationId, stationName, trains, необязательный needReload.
- Поезд: trainNo, toMoscow, departureTime, scheduleTime, delaySeconds, trainLength.
- Текстовые поля: i18n.ru.destination, i18n.ru.trainClass.name, i18n.ru.stops. Остальные переводы и поля типа поезда могут меняться.
- Данные и даты могут отсутствовать. Даты должны включать часовой пояс; секунды не округлять.
- Конечную брать из destination, не из softBreakDestination. stops показывать как текст, не разбирать в маршрут. Не запрашивать внутренние поля оборудования, from/to/ggs или SOS.

## Время и направление

Для движения используется departureTime. scheduleTime помогает сопоставлять рейсы; delaySeconds повторно не прибавлять.

toMoscow зависит от станции и может противоречить направлению: Рижская (3987) передавала false для поездов в обе стороны. Правила нормализации travelDirection описаны в [ARCHITECTURE.md](ARCHITECTURE.md). Исходный toMoscow сохраняется.

## Локальный API

- GET /api/health — состояние PHP-сервера.
- GET /api/state — опубликованный снимок расписания и состояние опроса. Браузер обращается только к локальному API.

Ошибки HTTP, таймауты, неверный JSON и несовпадение stationId фиксируются для станции; последняя успешная выдача сохраняется. needReload=true у любой станции включает немодальное предупреждение над картой, включая развёрнутый режим. Оно исчезает, когда флаг больше не присутствует ни у одной станции; движение и опрос продолжаются без перезагрузки. Номер версии источника в JSON не передаётся. Поезд без номера остаётся записью с причиной отсутствия позиции и не объединяется с другими станциями.
