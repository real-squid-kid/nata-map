# Интерфейс

Подтверждено пользователем 2026-10-07: светлая приборная панель в стиле скевоморфизма. Главный экран — карта с рабочими инструментами и карточками станций/рейсов.

- Материалы: светлый матовый корпус, утопленное поле карты, рельефные кнопки. Градиенты, границы, внутренняя тень и блик показывают глубину.
- Не перегружать карту декоративными текстурами. Поезда, станции и подписи должны различаться на подложке.
- Шрифт: Golos Text из Google Fonts, кириллица, веса 400/500/600/700. Резерв: Segoe UI, sans-serif.
- Цвета стартового каркаса: тёплый серый корпус, приглушённое зелёное поле, тёмный текст. Детали уточняются при просмотре карты.
- Тексты: названия станций, время, номер, конечная, режим расчёта, состояние источника. Без слоганов, рекламных заголовков и абзацев для заполнения пространства.
- Записи API без пригодных данных показывать с конкретной причиной; не заменять их вымышленными поездами.
- Карточка по клику закрепляется; наведение даёт краткую подсказку. Кнопки доступны с клавиатуры, видимый focus; hover не должен быть единственным способом получить данные.
- Реальная длина поезда — 160 м вдоль геометрии. Ширина и область клика — в пикселях.

Подтверждено 2026-10-07 после приёмки статичной карты:

- Окно карты слоёное. Снизу вверх: исходная подложка, затемнение, линии, станции, поезда. Подсказки, карточки и органы управления выше рабочих слоёв.
- Затемнение — отдельный полупрозрачный слой, сейчас 16%, значение в `config/app.json`. Он не перехватывает клики, не меняет PNG, не затрагивает линии/станции/поезда.
- Цвета: D1 `#ED9F2D`, D2 `#DF477C`, D3 `#E15D29`, D4 `#3CB183`. Линии, станции, тела поездов берут цвет диаметра из одного конфига.
- Голова состава белая, хвост красный; лёгкое свечение CSS. Голова расположена на +80 м по направлению движения от центра, хвост на −80 м. При обратном направлении они меняются местами. За границей геометрии огни не рисуются.

Отрисовка составов после уточнения пользователя:

- Ниже z14 — капсула цвета диаметра с белой обводкой и лёгкой тенью; огни головы/хвоста сохраняются.
- Днём с z14 — шесть схематичных SVG-вагонов: белый головной, четыре в цвете диаметра, красный хвостовой. Окна и крыша обозначены условно; крайние вагоны слегка светятся. Это векторные спрайты.
- Ночью корпус и инструменты темнее, отдельное затемнение карты 68% вместо 16%. До z14 включительно капсулы целиком светятся тёплым белым; с z15 шесть вагонов, голова светится белым, хвост красным. Выбор режима сохраняется в localStorage; PNG не меняются.
- Каждый вагон поворачивается по своему отрезку геометрии. Общая длина 160 м, между вагонами видимые зазоры; при выходе из покрытия вагоны обрезаются/исчезают.
- Направления разнесены на ±8 экранных пикселей от исходной линии, ширина вагона 10 пикселей. Это условные соседние пути, не данные о реальных путях. Расстояния и времена рассчитываются по исходной геометрии.
- Карточка станции показывает три следующих электрички в каждом направлении, отсортированных по `departureTime`. Выданный источником полный снимок и история не сокращаются.
- Порог, ширина, зазор, смещение и лимит отправлений находятся в `config/app.json`.

Подключение Tailwind: официальный [Vite plugin](https://tailwindcss.com/docs/installation/using-vite). Шрифт подключён через [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2); [метаданные Golos Text](https://raw.githubusercontent.com/google/fonts/main/ofl/golostext/METADATA.pb) содержат кириллические наборы.

Уточнения для планшета: выбор станции центрирует её на z15. Станции и расписание сворачиваются независимо; polling не сбрасывает состояние details. Панель подстраивается под окно без ограничения ширины 1600 px, боковая панель прокручивается отдельно. Кнопка ⛶ использует Fullscreen API, либо заполняет окно; повторный клик/Escape возвращает панель. При растворении меняется прозрачность всего состава, включая огни; конечная внутри D2 исчезает после стоянки без растворения.
