# Геометрия D2

## Источники

Рабочая линия получена из пользовательского GeoJSON рельсов D2 и соединённых продолжений OpenStreetMap у конечных. Она охватывает Нахабино — Подольск; это один репрезентативный путь, а не точные платформенные траектории.

Результат: 37 станций в порядке маршрута, линия из 1340 вершин длиной около 81,54 км. Исходный экспорт и кэш OSM хранятся в игнорируемой папке var/, не в Git. Атрибуция: OpenStreetMap contributors, ODbL.

## Повторный импорт

Положите исходный экспорт в var/d2_RAW.geojson. Для получения продолжений утилите scripts/extend-d2.mjs дополнительно нужен исходный ответ отношения OSM 10309306 в var/d2-route-full-preview.json. Утилита кэширует сетевые ответы в var/d2-extensions.geojson.

```powershell
node scripts/extend-d2.mjs
node scripts/import-d2.mjs
npm run check
```

Импорт проверяет непрерывность цепочки, порядок и проекции станций, накопленные расстояния и запас пути за конечными. Он формирует config/stations.json и config/railway.geojson. Повторная сборка приложения к OSM не обращается.

Запрос исходных рельсов сохранён в scripts/d2-geometry.overpassql. В каталоге config/d2-stations.json хранятся станционные данные и исходные названия; рабочие проекции находятся в config/stations.json.
