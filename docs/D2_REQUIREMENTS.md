# Покрытие D2

## Объём

Участок Нахабино — Подольск включает 37 станций; у 23 есть ID источника. Каталог — config/d2-stations.json, рабочие данные для карты и опроса — config/stations.json. У станций без API нельзя придумывать расписание.

ID Покровского — 3979, координаты 55.602998, 37.632022. Пл. трёх вокзалов (3986) возвращает HTTP 503; ошибка этой станции не должна останавливать опрос остальных.

## Ограничения

Точность положения не подтверждается GPS: карта показывает расчёт по расписанию. Источник не даёт уникальный ID рейса, сопоставление повторных номеров эвристическое. Одна геометрическая линия представляет участок, но не описывает реальные платформенные пути.

Постоянные правила описаны в [ARCHITECTURE.md](ARCHITECTURE.md); внешний вид — в [DESIGN.md](DESIGN.md). Импорт и проверки геометрии — в [D2_GEOMETRY.md](D2_GEOMETRY.md).
