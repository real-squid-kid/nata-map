# Полный D2: согласованные требования

Полный D2 подключён. Требования согласованы с пользователем; исходные ответы остаются локальными и исключены из Git. Геометрия и координаты проверены, один сборщик опрашивает 23 ID.

## Покрытие и источник

- Нахабино — Подольск. Каталог из 37 станций и 23 доступных ID API сохранён в `config/d2-stations.json`.
- Названия из TSV считаются правильными. Алиасы: Пл. трёх вокзалов → Каланчёвская, Люблино → Кубанская.
- Покровское: `55.602998, 37.632022`.
- ID Покровского исправлен с 3973 на 3979 по справочнику `/api/stations` источника 2026-10-07. Пл. трёх вокзалов (3986) там помечена как отключённая; её HTTP 503 не останавливает остальные станции.
- Показываем все пригодные электрички источника, останавливающиеся на станциях.
- Станции без API остаются на карте; расписание не выдумывается, движение рассчитывается по доступным временам и fallback.
- До остановки на Курской поезд идёт «на Москву», после — «от Москвы». Устойчивое направление по геометрии при этом не меняется. `toMoscow` нельзя использовать как постоянную часть ключа рейса на всём D2.

## Движение и исчезновение

- Реальные времена — якоря. При недостатке данных скорость 75 км/ч, условные промежуточные стоянки 30 с.
- Конечная Нахабино/Подольск либо другая распознанная конечная внутри D2: 120 с от прибытия и исчезновение. Обычные 30 с не прибавляются.
- Конечная вне D2: движение за край диаметра и постепенное растворение. Начальное значение — 30 с после отправления от крайней станции; меняется в конфиге. Требуется достаточно геометрии за краями.
- Рижский вокзал: линейное растворение за 30 с после отправления от Дмитровской. Алиасы Рижский вокзал / Москва-Рижская / Москва (Рижский вокзал); эта ветка не рисуется.
- Шесть вагонов: белая голова, четыре цвета диаметра, красный хвост; длина 160 м, два условных пути. Днём вагоны с z14, ночью с z15; ниже — капсулы, ночью целиком светящиеся тёплым белым.

## Опрос, тайлы, экран

- После полного цикла пауза 300 с; между началами upstream-запросов ≥1000 мс. Один сборщик, общая история, локальный polling 5 с.
- Thunderforest Free, расход >0,1% месячной квоты со слов пользователя; абсолютная квота не задана. Коридор 500 м, без массовой предзагрузки.
- Постоянный локальный кэш тайлов обязателен: повторный zoom, перезагрузка и соседняя вкладка того же origin используют сохранённые изображения. Проверено в Edge с подсчётом запросов.
- Основной экран — планшет Яндекс Станция Дуо Макс. Панель подстраивается под окно; карта разворачивается через Fullscreen API либо заполняет окно при недоступности API.
- Выбор станции центрирует её на z15. Список станций и расписание сворачиваются, polling сохраняет свёрнутое состояние. Три следующих отправления на направление.

## Проверка реализации

GeoJSON передан как `var/d2_RAW.geojson` и импортирован по [инструкции](D2_GEOMETRY.md). Продолжения реальной железной дороги у конечных достаточны для растворения за 30 с. Все 37 проекций проверены.

Рейсы сопоставляются по устойчивому направлению с трёхчасовым окном и защитой от повторов номера на одной станции. Карта, шесть вагонов, ночной режим, кэш, карточки, конечные и планшетное управление проверяются в headless Edge. Точность фактического движения не подтверждается без GPS; повторные номера и задержки продолжают наблюдаться по источнику.
