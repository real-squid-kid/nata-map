# nata-map

Локальная карта расчётных положений электричек на участке Стрешнево — Марьина Роща.

MVP-1: Leaflet-карта участка D2, пять станций, реальное расписание трёх станций, расчётное движение составов длиной 160 м, карточки поездов/станций и фильтрация тайлов по коридору 500 м.

## Окружение

Node.js 24.14.0+ в ветке 24, npm, PHP 8.2+. Версии пакетов закреплены в `package.json` и `package-lock.json`. Для Windows PHP должен быть доступен через PATH.

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

Открыть http://127.0.0.1:5173. `.env` создаётся один раз; существующий файл не перезаписывать. Значение `VITE_THUNDERFOREST_API_KEY` можно оставить пустым для работы с геометрией на сером фоне. После изменения `.env` перезапустить Vite.

Для расписания нужны ещё два терминала — PHP HTTP-сервер и единственный сборщик:

```powershell
npm run server
```

```powershell
npm run collect
```

PHP отдаёт `GET /api/health` и `GET /api/state`. Vite проксирует `/api` на `PHP_API_TARGET`, по умолчанию http://127.0.0.1:8080. Сборщик последовательно опрашивает три станции с интервалом ≥1 с, затем ждёт 120 с после цикла. Другой сборщик не запускается благодаря блокировке. `Ctrl+C` останавливает процесс; при перезапуске история и ограничения частоты сохраняются.

Для одного полного цикла есть `npm run collect:once` (при отсутствии другого сборщика). Ошибки не стирают последнюю успешную выдачу. Снимки хранятся в `var/`, HTTP не публикует каталог целиком. Браузер читает общий снимок каждые 5 с; несколько вкладок не умножают обращения к API МЦД.

В данной Windows-установке у PHP нет модулей curl/openssl; адаптер использует системный `curl.exe` с обычной проверкой TLS. На другой машине доступны PHP cURL либо системный curl.

```powershell
npm run check
npm test
npm run test:server
npm run build
php -l server/router.php
npm run preview
```

`preview` показывает сборку фронта на http://127.0.0.1:4173. Проксирование PHP настроено для `dev`; размещение готовой сборки с API будет настроено отдельно.

## Проверка карты

`npm run dev` достаточно для карты без расписания. Для MVP-1 запустить все три процесса выше. Ключ читается из `VITE_THUNDERFOREST_API_KEY` в `.env`. Без ключа остаются геометрия, станции и серый фон.

- «Весь участок» возвращает обзор; +/− и колесо меняют масштаб. Панорамирование ограничено областью участка.
- Наведение на маркер показывает название; клик по маркеру или станции в списке открывает карточку. Маркеры доступны с клавиатуры.
- «Диагностика карты» показывает число запросов, серых ячеек и ошибок с момента открытия страницы.
- В DevTools → Network → Img видны только разрешённые тайлы. У внешних `.corridor-tile[data-in-corridor="false"]` нет изображений или внешних `src`.
- Частично пересекающийся тайл отображается целиком; серые области — это отклонённые тайлы, а не строгая визуальная граница 500 м.
- При ошибке подложки геометрия остаётся видна, статус показывает недоступность/частичную загрузку; автоматических повторов нет.
- Слои снизу вверх: подложка → отдельное затемнение 16% → линии → станции → поезда. PNG остаются исходными. Цвета диаметров и степень затемнения в `config/app.json`.
- У составов D2 цвет `#DF477C`, белая светящаяся голова и красный светящийся хвост. Наведение — номер/конечная, клик — закреплённая карточка. Карточку также можно открыть из станционного расписания.
- Поезда с недостаточными данными остаются в списке «Без позиции на карте» с причинами. Старая выдача продолжает использоваться для движения; время последнего обновления показано.

Проходят 21 JS-проверка геометрии/движения/рейсов и PHP-проверки истории/нормализации/атомарной публикации. Реальный опрос всех трёх станций, HTTP-снимок через Vite и запрет второго сборщика проверены. Статичная карта и загрузка подложки приняты пользователем. Попытка проверки MVP-1 в Edge остановлена инструментом computer-use: текущий URL Windows-браузера не определён достаточно надёжно. Визуальная приёмка нового оформления/анимации остаётся открытой.

При запущенных процессах `node scripts/live-check.mjs` проверяет локальный API и расчёт по живым наблюдениям. Сопоставление одинакового номера использует временное окно 30 минут, история хранится 36 часов; это параметры MVP, уточняемые при наблюдении источника.

## Файлы

- `CONTEXT.MD` — короткий статус и следующий шаг.
- `AGENTS.md` — постоянные правила работы.
- `docs/ARCHITECTURE.md` — компоненты и правила расчёта.
- `docs/API.md` — минимальный неофициальный контракт API.
- `docs/DESIGN.md` — оформление и тексты.
- `docs/archive/` — неизменённая передача контекста и исходная архитектура.
- `config/` — параметры модели, пять станций, железнодорожная геометрия.
- `src/` — исходники фронта; `server/` — PHP; `var/` — будущие снимки и история, вне публикации.

Данные станций и геометрия восстановлены из исходного `CONTEXT.MD` без новых запросов Overpass. Это репрезентативный путь OSM для обоих направлений, не точные пути конкретного поезда. Атрибуция: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL-1.0.
