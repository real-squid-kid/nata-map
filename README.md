# nata-map

Локальная карта расчётных положений электричек D2 Нахабино — Подольск.

37 станций, 23 ID источника расписания, расчётное движение составов длиной 160 м с шестью вагонами, дневной/ночной режим, карточки и локальный кэш тайлов в коридоре 500 м. Положение рассчитывается по расписанию; GPS-данных нет.

## Окружение

Node.js 24.14.0+ в ветке 24, npm, PHP 8.2+. Версии пакетов закреплены в `package.json` и `package-lock.json`. Для Windows PHP должен быть доступен через PATH.

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

Открыть http://127.0.0.1:5173. `.env` создаётся один раз; существующий файл не перезаписывать. Значение `VITE_THUNDERFOREST_API_KEY` можно оставить пустым для работы с геометрией на сером фоне. После изменения `.env` перезапустить Vite.

Для расписания нужны ещё два терминала — PHP HTTP-сервер и единственный сборщик:

```powershell
npm run server
```

```powershell
npm run collect
```

PHP отдаёт `GET /api/health` и `GET /api/state`. Vite проксирует `/api` на `PHP_API_TARGET`, по умолчанию http://127.0.0.1:8080. Сборщик последовательно опрашивает 23 станции с интервалом ≥1 с, затем ждёт 300 с после цикла. Другой сборщик не запускается благодаря блокировке. `Ctrl+C` останавливает процесс; при перезапуске история и ограничения частоты сохраняются. Настройки сборщика читаются при запуске; увеличение паузы учитывается от последнего завершённого цикла.

Для одного полного цикла есть `npm run collect:once` (при отсутствии другого сборщика). Ошибки не стирают последнюю успешную выдачу. Снимки хранятся в `var/`, HTTP не публикует каталог целиком. Браузер читает общий снимок каждые 5 с; несколько вкладок не умножают обращения к API МЦД.

В данной Windows-установке у PHP нет модулей curl/openssl; адаптер использует системный `curl.exe` с обычной проверкой TLS. На другой машине доступны PHP cURL либо системный curl.

```powershell
npm run check
npm test
npm run test:server
npm run build
php -l server/router.php
npm run preview
```

`preview` показывает сборку фронта на http://127.0.0.1:4173. Проксирование PHP настроено для `dev`; размещение готовой сборки с API будет настроено отдельно.

## Проверка карты

`npm run dev` достаточно для карты без расписания. Для живого движения запустить все три процесса выше. Ключ читается из `VITE_THUNDERFOREST_API_KEY` в `.env`. Без ключа остаются геометрия, станции и серый фон.

- «Весь диаметр» возвращает обзор; +/− и колесо меняют масштаб в диапазоне z9–18. Панорамирование ограничено областью D2.
- Наведение на маркер показывает название; клик по маркеру или станции в списке открывает карточку. Маркеры доступны с клавиатуры.
- Выбор станции центрирует её на z15, включая крайние станции. Станции и расписание сворачиваются; polling сохраняет свёрнутое состояние.
- Кнопка ⛶ разворачивает карту на весь экран или заполняет окно при недоступности Fullscreen API. Повторный клик/Escape возвращает панель. Планшетный размер проверки — 1024×600.
- «Диагностика карты» отдельно показывает запросы к Thunderforest, попадания в локальный кэш, ожидающие загрузки ячейки и ошибки.
- Тайлы сохраняются в CacheStorage браузера (`nata-map-tiles-v1`): до 2000 изображений, срок 30 дней, плюс 128 изображений в памяти. Повторный zoom, перезагрузка и вкладки того же origin используют сохранённые тайлы; Web Locks объединяет параллельные запросы вкладок. Ключ кэша — стиль/z/x/y, без API-ключа. Для постоянного кэша нужны localhost или HTTPS и разрешённое хранилище браузера.
- В DevTools → Network → Fetch/XHR видны только недостающие разрешённые тайлы. Изображения отображаются через локальные blob URL. У внешних `.corridor-tile[data-in-corridor="false"]` нет изображений или запросов.
- Частично пересекающийся тайл отображается целиком; серые области — это отклонённые тайлы, а не строгая визуальная граница 500 м.
- При ошибке подложки геометрия остаётся видна, статус показывает недоступность/частичную загрузку; автоматических повторов нет.
- Слои снизу вверх: подложка → отдельное затемнение → линии → станции → поезда. Затемнение 16% днём и 68% ночью, PNG остаются исходными. Цвета диаметров и степени затемнения — в `config/app.json`.
- Днём ниже z14 — капсулы цвета D2 с обводкой/тенью, с z14 — шесть SVG-вагонов: белый головной, четыре `#DF477C`, красный хвостовой. Ночью капсулы целиком светятся тёплым белым до z14 включительно; с z15 — шесть вагонов со свечением белой головы и красного хвоста. Ночной режим затемняет корпус и сохраняется между открытиями страницы.
- Встречные направления разведены на условные соседние пути; длина состава остаётся 160 м. Параметры — в `config/app.json`.
- Наведение на поезд — номер/конечная, клик или Enter/пробел — закреплённая карточка. Карточку также можно открыть из станционного расписания: три следующих отправления в каждом направлении. Полный снимок источника сохраняется.
- Поезда с недостаточными данными остаются в списке «Без позиции на карте» с причинами. Старая выдача продолжает использоваться для движения; время последнего обновления показано.

Проверки охватывают геометрию всех 37 станций, движение, вагоны, историю, смену направления API через Курскую, повтор номера и атомарную публикацию.

Для UI установлен Playwright, запускающий отдельный headless Microsoft Edge без пользовательского профиля. Нужны установленный Edge, запущенные Vite/PHP/сборщик и рабочий ключ для сценария настоящей подложки:

```powershell
npm run test:browser
```

Шесть сценариев проверяют шесть вагонов, два пути, карточки, три следующих отправления, планшетное центрирование/сворачивание/полноэкранный режим, растворение Рижского рейса, ночной режим и постоянный кэш. Проверка кэша повторяет zoom кнопками и колесом, перезагружает страницу и открывает соседнюю вкладку: после прогрева новых запросов нет. Быстрый zoom во время загрузки не дублирует тайлы и не оставляет ложных ошибок. Синтетические сценарии подменяют Thunderforest по домену; только живой сценарий загружает настоящие видимые разрешённые тайлы. Скриншоты — в игнорируемом `var/qa/`, открытый Edge пользователя не используется.

При запущенных процессах `node scripts/live-check.mjs` проверяет все попытки опроса и расчёт по живым наблюдениям. Сопоставление одинакового номера использует устойчивое направление вдоль D2 и окно 3 часа, история хранится 36 часов. Повтор на той же станции с плановыми временами дальше 30 минут разделяется; `scheduleTime` используется только для идентичности, движение — по `departureTime`. Это эвристика, а не уникальный идентификатор источника.

Fallback — 75 км/ч, условные стоянки 30 с. Станции без API между известными якорями получают условные стоянки без изменения известных времён. Конечная внутри D2: 120 с от прибытия и исчезновение. Внешняя конечная: движение за Нахабино/Подольск и растворение за 30 с. Рижский вокзал: растворение за 30 с после отправления от Дмитровской.

Каталог — `config/d2-stations.json`, рабочие проекции — `config/stations.json`, реальная геометрия — `config/railway.geojson`. Исходный экспорт и продолжения обрабатываются по `docs/D2_GEOMETRY.md`. Справочник API подтвердил Покровское как ID 3979; ID 3973 из TSV исправлен. Пл. трёх вокзалов (3986) источник пометил `disabled=true`; HTTP 503 отображается как недоступное расписание, остальные станции продолжают работать.

## Файлы

- `CONTEXT.MD`, `AGENTS.md` — локальные инструкции LLM, исключены из Git.
- `docs/ARCHITECTURE.md` — компоненты и правила расчёта.
- `docs/API.md` — минимальный неофициальный контракт API.
- `docs/DESIGN.md` — оформление и тексты.
- `docs/D2_REQUIREMENTS.md` — согласованные требования полного D2.
- `config/` — параметры модели, 37 станций, железнодорожная геометрия.
- `src/` — исходники фронта; `server/` — PHP; `var/` — будущие снимки и история, вне публикации.

Локальные ответы, архив передачи контекста и материалы исключительно для LLM исключены из Git; уже отслеживавшиеся инструкции убраны из индекса с сохранением файлов. Публичная документация проекта остаётся в `docs/`.

Геометрия — проверенный пользовательский экспорт отношения OSM 10309306 и реальные продолжения рельсов через OSM API. Это репрезентативный путь для обоих направлений, не точный путь конкретного поезда. Атрибуция: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL-1.0.
