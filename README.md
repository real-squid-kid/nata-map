# nata-map

Локальная карта расчётных положений электропоездов D2 Нахабино — Подольск. В пути 37 станций, из них 23 опрашиваются по API. Положение поездов рассчитывается по расписанию: GPS координат нет.

## Запуск

Нужны Node.js 24, npm и PHP 8.2+ в PATH. Если `.env` ещё нет, создайте его копией `.env.example`; укажите публичный ключ Thunderforest по желанию. Уже существующий `.env` сохраняйте. Установите зависимости при первом запуске или изменении `package-lock.json`, затем запустите проект в одном терминале:

```powershell
npm ci
npm run start
```

Откройте [карту](http://127.0.0.1:5173) после сообщения о готовности. Команда проверяет PHP, порты 5173/8080 и блокировку сборщика, запускает PHP и Vite, дожидается их готовности и запускает сборщик. Логи всех сервисов идут в этот терминал с пометками источника. **Ctrl+C останавливает процессы этого запуска.** Если сервис завершится, остальные тоже остановятся. Уже работающие сервисы нужно остановить самостоятельно перед единым запуском.

Карта работает и без ключа, но подложка будет серой. Сборщик опрашивает станции по очереди с интервалом не менее секунды и ждёт 300 секунд после цикла; перезапуск сохраняет эту паузу. Первое расписание может появиться не сразу. Локальные снимки находятся в `var/`; HTTP не раздаёт эту папку.

Проверка состояния: [API](http://127.0.0.1:8080/api/health) и [снимок расписания](http://127.0.0.1:5173/api/state). Для отладки сохранены отдельные команды `npm run dev`, `npm run server`, `npm run collect` (каждая в своём терминале). Для одного цикла вместо постоянного сборщика — `npm run collect:once`; не запускайте его одновременно с `npm run start`.

## Проверки

```powershell
npm run check
npm test
npm run test:server
npm run build
php -l server/router.php
```

Браузерные проверки запускают отдельный headless Microsoft Edge. Синтетические сценарии подменяют тайлы; сценарий с настоящей подложкой требует работающих сервисов и расходует квоту Thunderforest:

```powershell
npm run test:browser -- --grep-invert '@live'
npm run test:browser
```
