# nata-map

Локальная карта расчётных положений электропоездов D2 Нахабино — Подольск. В пути 37 станций, из них 23 опрашиваются по API. Положение поездов рассчитывается по расписанию: GPS координат нет.

## Запуск

Нужны Node.js 24, npm и PHP 8.2+. Если `.env` ещё нет, создайте его копией `.env.example`; укажите публичный ключ Thunderforest по желанию. Уже существующий `.env` сохраняйте. Запустите в отдельных терминалах:

```powershell
npm ci
npm run dev
npm run server
npm run collect
```

Откройте http://127.0.0.1:5173. Карта работает и без ключа, но подложка будет серой. Для расписания должны работать все три процесса: Vite, PHP и единственный сборщик. Сборщик опрашивает станции по очереди с интервалом не менее секунды и ждёт 300 секунд после цикла. Локальные снимки находятся в `var/`; HTTP не раздаёт эту папку.

Проверка состояния: http://127.0.0.1:8080/api/health и http://127.0.0.1:5173/api/state. Для одного цикла вместо постоянного сборщика можно использовать `npm run collect:once`.

## Проверки

```powershell
npm run check
npm test
npm run test:server
npm run build
php -l server/router.php
```

Браузерные проверки запускают отдельный headless Microsoft Edge. Синтетические сценарии подменяют тайлы; сценарий с настоящей подложкой требует работающих сервисов и расходует квоту Thunderforest:

```powershell
npm run test:browser -- --grep-invert @live
npm run test:browser
```
