# nata-map

> Внимание: этот проект подготовлен и собран с помощью ИИ. Если вам это не нравится, изложите свои претензии на бумаге, придайте этому листу бумаги форму супппозитрория и засуньте себе этот лист бумаги туда, куда солнце не светит. Любое нытье касательно ИИ будет игнорировано.

Локальная карта расчётных положений электропоездов D2 Нахабино — Подольск. В пути 37 станций, из них 23 опрашиваются по API. Положение поездов рассчитывается по расписанию: GPS координат нет.

## Запуск

В ветке `no-server` нужен только Node.js 24 и npm. PHP и отдельный сборщик не запускаются. Если `.env` ещё нет, создайте его копией `.env.example`; укажите ключ Thunderforest по желанию. Этот ключ виден браузеру в URL тайлов, поэтому ветка предназначена только для локальной проверки. Установите зависимости при первом запуске или изменении `package-lock.json`, затем запустите проект:

```powershell
npm ci
npm run start
```

Откройте [карту](http://127.0.0.1:5173) после сообщения о готовности. `npm run start` запускает один Vite-процесс; **Ctrl+C его останавливает**. Расписание браузер получает напрямую от Nata Info. Вкладки одного браузера выбирают одного опросчика; данные и время следующего цикла хранятся в IndexedDB.

Карта работает и без ключа, но подложка будет серой. Опросчик обращается к 23 станциям по очереди с интервалом не менее секунды и ждёт 300 секунд после цикла; перезагрузка вкладки сохраняет паузу. Первый полный цикл занимает минимум 23 секунды плюс время сети. При закрытии всех вкладок опрос прекращается. Каждое отдельное устройство ведёт свой опрос.

Внизу карты видны число обновлённых станций и время последнего ответа. Станции без API остаются без расписания. Правила движения и время `departureTime` не изменились.

Для демонстрационного экрана откройте [карту сразу на всё окно](http://127.0.0.1:5173/?fullScreen=true). Параметр `fullScreen=true` работает и с `/index.html?fullScreen=true`: боковая панель, шапка и подвал скрыты с первого отображения. Кнопка «Свернуть карту» или Esc возвращает обычный интерфейс; перезагрузка этой ссылки снова разворачивает карту. Режим занимает окно браузера.

## Проверки

```powershell
npm run check
npm test
npm run build
npm run test:browser
```

Браузерные проверки запускают отдельный headless Microsoft Edge и подменяют ответы API и тайлы, не расходуя квоту Thunderforest. Им нужен запущенный Vite. Старые сценарии с PHP-снимком сохранены в `scripts/browser/map.spec.js` для сравнения и в этой ветке не запускаются.
