# nata-map

- Общение, документация и UI: русский. Часовой пояс: Europe/Moscow.
- Перед работой прочитать `CONTEXT.MD`. Детали открывать по задаче: `docs/ARCHITECTURE.md`, `docs/API.md`, `docs/DESIGN.md`.
- Не загружать архив и полные координаты GeoJSON в контекст без необходимости. Данные читать программно.
- После завершённого этапа обновлять статус и следующий шаг в `CONTEXT.MD`. Не дублировать там документацию и JSON.
- Фронт: Node.js 24, Vite, обычный JavaScript ES-модули, Tailwind CSS 4, Leaflet 1.9.4. Сервер и отдельный сборщик: PHP 8.2+.
- MVP ограничен пятью станциями участка Стрешнево — Марьина Роща. API опрашивается только для 4127, 4128, 4129.
- Сохранять решения о движении и опросе из архитектуры. Не менять `departureTime` на `scheduleTime` и не прибавлять задержку молча.
- Тайлы вне коридора не должны получать внешний `src` или `fetch`. Один сборщик обслуживает все вкладки.
- Ключи: локальная `.env`, вне исходников. Thunderforest-ключ с префиксом VITE_ публичен в браузере; не помещать туда серверные секреты.
- UI: светлая скевоморфная приборная панель, кириллический Golos Text. Только содержательные подписи и состояния, без продающих заголовков и текста для заполнения места.
- Базовая проверка: `npm run check`, `npm run build`, `php -l server/router.php`. Новое поведение проверять по критериям соответствующего этапа.
- Не объявлять карту, расписание или движение готовыми по наличию каркаса либо схемы.
