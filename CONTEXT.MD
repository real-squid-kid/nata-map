# nata-map: рабочий контекст

Обновлено: 2026-10-07. Язык: русский. Время: Europe/Moscow.

## Задача

Локальный MVP карты расчётных положений электричек на участке D2 Стрешнево — Марьина Роща. API опрашивается только для Дмитровской (4127), Гражданской (4128), Красного Балтийца (4129). Полный МЦД, GPS, точные станционные пути и удалённые конечные вне MVP.

## Подтверждённый стек и оформление

- Фронт: Node.js 24, Vite, JavaScript ES-модули, Tailwind CSS 4, Leaflet 1.9.4.
- Сервер и отдельный CLI-сборщик: PHP 8.2+, JSON-состояние без обязательной БД.
- Светлая скевоморфная приборная панель, Golos Text из Google Fonts с кириллицей.
- Только содержательные тексты интерфейса; без продающих заголовков и заполнителей.
- Сейчас localhost; позднее пользователь перенесёт на TimeWeb. Деплой не требуется.

## Неизменяемые предметные решения

- `departureTime` — якорь; прибытие −15 с, отправление +15 с. Не округлять секунды, не прибавлять `delaySeconds`.
- Между известными временами движение равномерное по расстоянию; fallback 60 км/ч с 30-секундными стоянками на станциях конфига.
- Состав 160 м вдоль изгибов пути, центр на станции. Известная конечная: 120 с с прибытия, затем исчезновение. Удалённая: исчезновение после полного выхода из покрытия.
- `toMoscow=true` увеличивает `alongTrackMeters` именно на этом участке.
- Рейсы сопоставляются по `trainNo` и временному окну/дате целого рейса, без дубля через полночь. Недостаточные записи сохраняются с причинами. `stops` — только текст.
- Один сборщик, последовательные станции; минимум 1000 мс между началами любых upstream-запросов, 120 с паузы после цикла. История сохраняется; ошибки не стирают последнее успешное расписание и не замораживают движение.
- Thunderforest Transport: тайл разрешён при пересечении прямоугольника с 500-метровым коридором. Внешние тайлы серые, без запроса. Только браузерный кэш просмотренного; без прокси и массовой предзагрузки.
- Слои снизу вверх: подложка → затемнение → линии → станции → поезда. Затемнение — отдельный слой 16%, без изменения PNG и без затемнения объектов; процент в `config/app.json`.
- Цвета линий, станций и поездов: D1 #ED9F2D, D2 #DF477C, D3 #E15D29, D4 #3CB183. Голова состава белая и слегка светится, хвост красный и слегка светится; расположение зависит от направления движения.

## Открытые вопросы

- Ключ Thunderforest работает; исходная карта принята пользователем.
- В живом примере departureTime уже включает отклонение −90 с от scheduleTime; задержка повторно не прибавляется. Полная семантика источника при разных задержках ещё не исследована. `build=84` сейчас работает.
- Zoom 12–18, обзор ≤14. Для MVP-1 окно объединения одинакового trainNo/направления 30 минут, история 36 часов; это эвристики короткого участка, уточняемые по живым данным.
- В локальном PHP нет curl/openssl: адаптер использует системный curl.exe с обычной проверкой TLS. На сервере доступен PHP cURL либо системный curl.
